# Site institucional — Lumeo Android

Site estático independente do aplicativo. Não contém autenticação, catálogo, backend ou credenciais.

## Publicar na Vercel

1. Importe este diretório (`lumeo-android-site`) como um novo projeto na Vercel.
2. Configure **Framework Preset: Other** e deixe o campo Build Command vazio.
3. Configure **Output Directory: `.`**.
4. Faça o deploy. A Vercel fornece HTTPS automaticamente.
5. Para um domínio próprio, adicione-o em **Settings → Domains** e atualize os links canônicos, `sitemap.xml` e `robots.txt`.
6. Use a URL HTTPS publicada como homepage, política de privacidade e termos no Google Cloud Console durante a verificação OAuth.

Nenhum deploy foi realizado por este projeto.
